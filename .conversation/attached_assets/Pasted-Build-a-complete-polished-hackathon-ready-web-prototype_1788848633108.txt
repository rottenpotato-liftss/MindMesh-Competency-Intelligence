Build a complete, polished, hackathon-ready web prototype called **MindMesh**.

### 1. PROJECT PURPOSE

MindMesh is an AI-enabled learning and competency platform for India's Official Statistical System.

Problem: Statistical officials need continuous upskilling in statistics, technology, digital governance and managerial skills. Existing learning platforms provide courses but do not intelligently identify competency gaps or personalize learning based on an employee's role, experience, previous training and future requirements.

MindMesh turns learning into a continuous, intelligent and engaging experience through AI, competency intelligence and gamification.

### 2. CORE SOLUTION

Create this continuous AI learning loop:

**PROFILE → ASSESS → ANALYZE → IDENTIFY SKILL GAPS → PERSONALIZE → RECOMMEND → LEARN → GENERATE QUIZ → ASSESS → AI FEEDBACK → UPDATE COMPETENCY → GROW SKILL GARDEN → UPDATE SKILL DNA → EARN SHIELDS → RECOMMEND AGAIN**

The prototype must demonstrate:

1. AI competency assessment
2. Automated skill-gap analysis
3. Personalized learning pathways
4. iGOT Karmayogi course recommendations/integration demo
5. NSSTA/TPAC training-program recommendations
6. AI-generated MCQs/quizzes from uploaded learning materials
7. AI feedback and competency updates
8. Learner and admin dashboards
9. **Skill Garden — visual growth based on learning activity**
10. **Skill DNA — dynamic visual representation of the learner's skills**
11. **Shield-based achievements inspired by competitive gaming progression**
